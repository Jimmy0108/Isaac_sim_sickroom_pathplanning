# V6.6 Isaac Sim 置換與測試

## 交付內容

- AGV_configured_v66.usd：完整新幾何與11剛體、10關節、6原生Cylinder輪地碰撞、車身分塊碰撞。原檔未改。
- AGV_control_v66.usd：舊差速控制圖，輪半徑0.08m、輪距0.4769668332689978m；有效左右關節名稱及目標路徑已寫入。
- V66_TestScene.usda：單一PhysicsScene、平地與新版車體/控制引用。240Hz是初始穩定性設定，並不代表能即時執行。
- V66_ManualPanel.py：Script Editor手動按鈕，無自動行駛、無導航、無避障、無直行補償。
- vehicle_geometry_config.json：Python odom等須同步的新參數，舊程式不會自動讀取此檔。
- validation.json：離線USD結構及錨點驗證；不是Isaac Sim運行驗收。

## 先在平地試車

1. 關閉舊導航/遙控腳本與面板，按Stop。建議重新開啟Isaac Sim後直接測此獨立場景，避免舊session layer與Python任務繼續寫指令。
2. 將整個Isaac_V6_6_Migration資料夾上傳到遠端new_car下。不可只上傳測試場景：它使用同資料夾內的兩個USD相對引用。
3. File → Open，開啟V66_TestScene.usda。不要把它拖入已開啟的病房場景，以免同時多一個地板與PhysicsScene。
4. Window → Script Editor，開啟同資料夾V66_ManualPanel.py，按Run，再按Play。
5. 等面板READY，並親眼確認車身落地、停穩。面板的3秒等待不是物理穩定性判定。先以預設0.20m/s前進，再按STOP；確定停穩後再倒退、左轉、右轉。切換方向前必須STOP；不要直接從旋轉切到直走。
6. 檢查是否有輪子懸空、穿地、持續跳動、明顯偏行。若異常立即Stop，不要開導航腳本或加航向補償。面板沒有障礙防護，只適用獨立空曠試車。
7. 低速可用後，才能勾選0.90上限做短距離測試。數值是模擬速度，不會修復低RTF。

## 平地通過後替換病房引用

1. Stop，File → Save As另存病房副本。不要覆蓋原始病房檔。
2. Stage選取 /World/AGV_configured_v4，Property中展開原本References或Payloads。記下該外層Xform的Translate/Rotate/Scale。
3. 只將舊車體資產路徑改成同資料夾的AGV_configured_v66.usd，Prim Path用DefaultPrim。保持Stage名稱AGV_configured_v4不變。不要另加第二台車，也不要更改外層比例。
4. 同樣選 /World/AGV_control，將原控制資產換成AGV_control_v66.usd，DefaultPrim；保持名稱AGV_control。
5. 展開確認新base_link位於 /World/AGV_configured_v4/TZAGV_B02_vendor_v4/TZAGV_B02_root/base_link。控制圖位於 /World/AGV_control/AGV_DifferentialGraph。
6. 新車基準輪底Z=0，外層Translate Z應使其位於病房地面上方約1cm起落。舊場景可能有約-2.x m的地面，不可把它直接改成Z=0。保持車身直立，只有Z軸朝向旋轉；若外層有非1比例或X/Y傾斜，先排查。
7. 若主場景在子層base_link/輪組/控制圖另有舊overrides，必須在Layer/Property Stack確認後移除對應舊意見，否則它們仍可能壓過新版。不要清除整個Session Layer或病房其他設定。無法辨識時先保持場景不動並提供層資訊。
8. 確認只有一套有效車體/控制及預期PhysicsScene，再用同面板低速試車，通過才保存。

## Python 導航尚須同步

將既有程式的輪半徑0.09改0.08、輪距0.514改0.4769668332689978；保留光達端base_link -X車頭、linear command sign=-1、angular sign=+1。邏輯左輪是right_wheel_joint、邏輯右輪是left_wheel_joint，encoder符號兩側均-1。OmniGraph輸出順序仍是left_wheel_joint/right_wheel_joint；不要因命名反向而自行對調兩套介面。

不要執行舊R90/R30碰撞修復、舊joint重設或舊幾何bootstrap。這次未取得你遠端當前完整導航程式，沒有宣稱已修改其odom。不要只複製JSON就以為舊程式會自動讀取。

## 本包的工程假設與限制

質量沿用舊檔base60kg、驅動輪2kg、轉向支架0.5kg、萬向輪0.3kg。慣量使用箱體/圓柱估計，base重心先設Z=180mm；它們不是CAD精確質量屬性，需運行驗證。驅動Drive保留提供檔案的damping100、maxForce5，沒有偷偷增加力矩。萬向輪關節為自由被動關節，沒有目標速度馬達。

輪地摩擦暫定static0.7/dynamic0.6/restitution0，屬明確初始設定而非已校準值；沒有修改Max Depenetration Velocity。關節與輪地幾何離線對齊不代表受重力後必定平穩。

複合車身碰撞是簡化箱體，保留前後凹槽；外包覆使用薄凸Mesh碰撞。不是完整細節三角網格碰撞，也未檢驗全部接觸對。

Lidar_2D保留舊RTX profile（未擅自改後端），移到(-0.23,0,0.345)m、RotateZ180。此光學平面是暫定，舊profile本身也未在本機Isaac驗證；若導航採PHYSX_COLLISION_RAYCAST，仍需更新其外參與自車過濾。D555只含外觀，未啟用深度感測。此包可先做移動驗證，不能直接宣稱可建圖導航。
