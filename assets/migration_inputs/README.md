# V6.6 僅調整萬向輪接地高度

以 V6.5 為來源。四組萬向輪上方安裝板、固定螺栓、轉向軸安裝點、轉向軸承與頂部橋接保持原位。只延長下方叉架腿，輪軸、輪軸螺帽/墊片與完整滾輪組向下16.5mm。輪胎、輪轂均為剛性平移，沒有縮放；萬向輪直徑63mm、驅動輪直徑160mm、驅動輪心距476.966833mm不變。全部輪組XY位置、車殼及原V6.5其他Mesh世界座標均經程式比對。

保存後重新開啟 Blender 及 USD，確認四萬向輪輪胎與碰撞代理、兩驅動輪碰撞代理底部Z皆約0，容許浮點誤差0.002mm。實測及USD路徑見validation.json。車殼長寬高、車體總高、外包覆、上下板、光達與D555均未修改。整車幾何最低點原已為驅動輪Z=0，故降低萬向輪並不增加整車外廓高度。

joint_migration_REFERENCE_ONLY.json 更新了四個滾輪軸關節 localPos0 的Z，原轉向安裝錨點不變。這是移植參考，未寫入實際物理Joint；不是執行檔。USD內碰撞形狀仍為purpose=guide的Mesh；移植時可轉為原生Cylinder後啟用CollisionAPI。未啟用剛體、質量、關節、感測器，也未做Isaac Sim接觸/行走驗收。

此版本為使用者選擇的共面剛性支撐幾何，與原STEP靜態萬向輪底部+16.5mm的裝配不同。不是宣稱修正原廠CAD錯誤或已確認實車懸吊狀態。叉架是幾何設計修改，製造強度、孔位/工藝尚未驗證。

不覆寫V6.5。模擬仍須完成物理移植並驗證受重力落地後輪地接觸；六輪共面不是穩定行駛保證。
