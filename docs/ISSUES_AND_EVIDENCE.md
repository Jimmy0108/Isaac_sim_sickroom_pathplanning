# 問題、證據與修正

整理 10 月至 11 月的對話、保存程式與選錄實跑。狀態用「程式確認」「單次實跑」「離線檢查」「待驗證」標明。

| 事件 | 證據與原因判讀 | 處理位置與結果 |
|---|---|---|
| 匯入後缺少 Joint | link 名稱存在，USD 尚無物理關節 | 新增剛體、碰撞、十個關節及唯一差速控制鏈。幾何可開啟與動態可行分開驗收 |
| 車頭與控制方向錯置 | 光達端為 −X，早期曾以 +X 作車頭 | front_axis_sign、linear_command_sign 與邏輯左右綁定，見參數表 |
| 保護區近回波與 44/72 方向判斷 | 有回波方向數不代表發射覆蓋率，單一位置地圖也有遮擋未知區 | 20261014 舊程式移除錯誤門檻，保留資料有效及過期檢查 |
| 初始高度與落地後地圖不同 | Stop 前車身未落地，Play 後高度改變 | 改成等待落地穩定後建圖與導航，後續採 odom＋SLAM |
| 模型 AABB 覆蓋床下區 | 重建 mesh 全域外框將空隙視為實心 | 早期用簡化碰撞代理，後續由碰撞射線和占據格網建圖 |
| 多個 base_link 搜尋歧義 | 病房手臂及車體都有同名節點 | 配置明確 prim 路徑，完整核對 controller、base、lidar |
| 面板啟動後消失、PhysX view 失敗 | 模擬附掛前建立 view 或重複初始化 | 等待物理事件，復用已附掛 simulation view，保留錯誤面板 |
| Script Editor 名稱遺失 | 曾發生 MODULES 未定義，非同步 globals 來源不同 | AMR_V66_Navigation.py 用同一閉包、顯式模組來源及清理順序 |
| 掃描存在但 SLAM 拒絕 | 新鮮度與配準品質為不同條件 | 輪角按物理步記錄並按掃描時刻插值，配準拒絕時暫停地圖整合 |
| 雙 PhysicsScene／兩倍時鐘增量 | 歷史 callback dt 1/240，manager 增量約 1/120，同時見兩場景 | 核對引用後停用重複場景，逐步比對。歷史 6062 步一致為該次紀錄 |
| RTF 約 0.02003 | 約 13.9917 模擬秒／698.411 現實秒 | 慢約 49.9 倍，不能用十倍命令速度取代效能修復。讀場景步長並記雙時鐘 |
| 手動 w＝0 仍偏行 | 命令、實際輪速、輪心與接觸可能不一致 | V66 手動無航向補償，記錄實際輪角與車身，避免以補償掩蓋接觸問題 |
| 舊 USD 缺左前萬向輪碰撞 | 實際舊檔僅五輪碰撞，且暫存修正未全部保存 | 新 configured 建立六輪原生圓柱碰撞，更新 link、錨點與控制器 |
| STEP 萬向輪底高 16.5 mm | 原靜態裝配狀態不同於剛性共面模擬 | V6.6 延長叉架並降低滾輪 16.5 mm。輪徑、輪距和 XY 維持基準 |
| 前左 swivel 阻尼為零 | 與其餘約 0.000349066 不一致 | MatchFrontLeftSwivel 於 root layer 對齊前右既有值，儲存主場景後持久 |
| 旋轉後直行短暫偏擺 | 萬向輪偏角約 46°–59°，重排期間 yaw 偏差集中 | 停穩交接仍保留。被動輪需移動才能迴正，唯一根因未確定 |
| 高速輪速追蹤瞬態 | 曾見相同 +11.25 rad/s 目標，一輪實際短暫 −1.16 rad/s | 查 drive、接觸與求解步長，單次資料不支持任意增加阻尼或力矩 |
| 材質候選測試 | 萬向輪 static 0.25／dynamic 0.20，驅動輪維持 0.70／0.60 | CasterContactCandidate 為 Session layer 候選。實跑速度不同，不能算因果改善百分比 |
| 地圖保存按鈕混淆 | Finish、Confirm、Export 各作用不同 | Finish 凍結候選，Confirm 更新正式圖，Export 僅匯出工作紀錄 |
| 估計抵達與世界真值不同 | V66 1.0 曾估計約 4.51 cm，前次世界位姿評分約 22.9 cm | 標為流程跑通，定位精度待改善。世界位姿只作獨立評分 |
| 綠線大折角 | Smooth 1.1 已執行，但路徑含約 67°、129°、11.6° spin 及換向 | 先查規劃動作，2.0 加入連續優先搜尋、終點連接與 CG 候選 |
| STOP_NOT_VERIFIED 過早 | 68.183 s 要求 replan，沿用 60.450 s 計時，68.467 s 中止 | 1.1.1 重設 action_started，實際此前僅等 0.283 s，保留 8 s 真停穩檢查 |
| 接觸空紀錄 | wheel_contact_1793978770577875223 回報 0 callbacks | 無法以空紀錄判定沒有接觸或滑移 |
| 弧線繞路 | 影片可見連續轉向，2.0 可能以較長路線換取無 spin | 比較路長、時間、最小淨空及停轉次數。無同條件優劣定論 |
